# Trading-new

## Patrones estructurales

El análisis identifica dobles techos y suelos, hombro-cabeza-hombro (incluida
su versión invertida), triángulos ascendentes/descendentes/simétricos, cuñas,
rectángulos, banderas y banderines. El gráfico principal marca pivotes y líneas
mientras se forman. Las señales se emiten tras una ruptura confirmada por vela
cerrada y usan el flujo habitual de aprendizaje del bot.

Las referencias describen patrones y resultados históricos de acciones, no una
garantía de rentabilidad en opciones binarias de un minuto. Los patrones
añadidos son candidatos técnicos; su rentabilidad debe validarse con datos
históricos del activo, costes y vencimiento reales.
El detector trabaja con OHLC; no dispone de volumen para validar expansiones
en la ruptura.

Como referencia histórica, la tabla de Bulkowski de 2020 sitúa la taza con asa
en el puesto 3 y el rectángulo superior en el puesto 4 para rupturas alcistas
en mercados alcistas; esos resultados no equivalen a una tasa de acierto para
este bot ni para velas de un minuto.
