# Trading-new

## Patrones estructurales

El análisis identifica dobles techos y suelos, hombro-cabeza-hombro (incluida
su versión invertida) y triángulos ascendentes o descendentes. El gráfico
principal marca los pivotes y líneas del patrón mientras se forma. Una señal
solo se emite cuando una vela cerrada rompe el nivel de confirmación; después
usa el flujo habitual de señales y aprendizaje del bot.
